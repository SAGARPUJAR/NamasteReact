Now once we build the project we get error as @parcel/transformer-js: Browser scripts cannot have imports or exports.
since the javascript which we called in index.html (<script src="./App.js"></script>) is considered as normal browser script and browser script doesnt understand what is the import or rxport statements.
In order avoid these error we need to make sure the script we called we need to add type = "module"  while calling the script (eg. <script type="module" src="./App.js"></script>)

- Code splitting
