When root.render is called it takes the react element and convert this to HTML element and show in the UI (When root.render() is called, React takes the React Element (a JavaScript object), creates the corresponding DOM elements, and inserts or updates them in the browser's DOM so they appear as HTML on the UI.)

As you can see when creating the react elements it takes time write and its becoming more code. So what facebook/meta developers did was they created something called JSX

JSX: JavaScript XML, which is help us to create an HTML elemenets within the JS file
JSX is not part of React.
JSX -> Merges the HTML and JavaScript together
JSX  - Its HTML LIKE or XML like syntax
syntax:
// JSX  - Its HTML LIKE or XML like syntax
const jsxHeading = <h1 id="intHeaderId">Namaste React 🚀🚀 Using JSX</h1>;

Is above code is understand by Js Engine ?? NO -> It will understand the ECMA Script
and the code which we written is not a valid Pure javascript code and JS engine will not understand this.

If it is not understand by the browser how this is rendered in the UI??
Because Parcel is doing the job for us. even before going to JS engine it is transpiled.(the code is converted to Javascript Engine understandable)
JSX (Transpiled before it reaches to JS engine) -> Who does this Parcel -> Parcel alone cannot do this and we have something called Babel 
JSX -> Parcel -> Babel
JSX -> Converted to React.Element Behind the scenes -> JS Object -> HTML element (render)	

We aritting this code for Machines or Humans ? => We are writting for both, First for human and then for machine
