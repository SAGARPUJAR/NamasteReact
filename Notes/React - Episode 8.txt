What is constructor(props)
	- constructor() is a JavaScript class constructor.
	- It runs when React creates an instance of your class component.
	- constructor(props) { }
	- "The component is being created. Do any initial setup here."
	
What is super()?
	- This is actually JavaScript, not specifically React.
	- class UserClass extends React.Component
	- So UserClass is a child class of React.Component.
	- In JavaScript, when a child class has a constructor, you must call: super();

Why super(props) instead of just super()?
	- This is the important part.
	- class UserClass extends React.Component {
		constructor(props) {
			super(props);
		
			console.log(this.props);
		}
		
		render() {
			return <h1>{this.props.name}</h1>;

		}

- React lifecycle method (https://projects.wojtekmaj.pl/react-lifecycle-methods-diagram/)
There are 2 phases 
	1. Render Phase -> Pure and has no side effects. May be paused, aborted or restricated by React
	2. Commit Phase -> Can work with DOM, run side effects, schedule updates.

when multiple components are called the react will batch the constructor and Render method batch then commit phase will execute together. This is where the react doing the optimization
- why this is happening ?
	when we are updating the Mounting the DOM manipualtion is expensive and it takes a lot of time to update.
	this is the reason react will batch the components and updates the DOM
	By doing this react is doing the performance optimzation

import React from "react";

class UserClass extends React.Component {
  constructor(props) {
    super(props);
    this.state = {
      count: 0,
      userInfo: {
        name: "Dummy Name",
        location: "Dummy Location",
        avatar_url: "https://via.placeholder.com/280x180",
        blog: "Dummy Blog",
        repos_url: "Dummy Repos URL",
      },
    };
    // console.log(this.props.name + " Constructor");
  }
  async componentDidMount() {
    const data = await fetch("https://api.github.com/users/sagarpujar");
    const json = await data.json();
    console.log(json);

    this.setState({
      userInfo: json,
    });
  }

  render() {
    // console.log(this.props.name + " Render");
    // const { name, rating, price, description } = this.props;
    const { count } = this.state;
    const { name, location, avatar_url, blog, repos_url } = this.state.userInfo;
    return (
      <div className="card">
        <h2>count : {count}</h2>
        <button
          onClick={() => {
            this.setState({
              count: this.state.count + 1,
            });
          }}
        >
          Increase
        </button>
        <button
          onClick={() => {
            this.setState({
              count: this.state.count - 1,
            });
          }}
        >
          Decrease
        </button>
        <img className="card-img" src={avatar_url} alt="Restaurant" />

        <div className="card-content">
          <h2 className="card-title">{name}</h2>

          <p className="card-rating">{location}</p>

          <p className="card-description">{blog}</p>

          <p className="card-price">{repos_url}</p>
        </div>
      </div>
    );
  }
}

export default UserClass;

---------------UPDATING-----------------------------
1. Render(API DATA)
2. <HTML> New Data
3. Component Did Update is called
