* useEffect() Hook =>
	- Called from react library using named import {useEffect}
	- It takes 2 arguments 
		1. Call back funciton
		2. Depedency array
	- useEffect(()=>{
		console.log("Use Effect called")
	  }, [])

	- useEffect called when component re-renders
	- Since we are using dependency array it changes the behaviour of the useEffect => What does mean by this ??
		- If no dependency array it called on every render.
		- If dependency array is empty [] => It will only on the intial render and just once =>  not called on every render
		- What if we pass anything on the dependency array ? then it will be called only when dependency changes
		
* useState() Hook =>
	- create useState() hook within the component fucntion, instead of creating outside function
	- It is use to create the local state variables inside your functional component
	- use useState top of the fucntion => So that we dont have inconsistency in our code. Since JS is synchronous single htreaded languge when it executes it creates the state variable intially and helps devs to implement the code without any error and its good practise
	- Never create a useState withing the if else, loops and functions anyother conditions and keep outside

- react-router-dom provides the useRouteError() hook -> It provides the more information about the error.
- Example:
	import { useRouteError } from "react-router";
	
	const Error = () => {
		const err = useRouteError();
		return (
			<>
			<h2>Error Page</h2>
			<h3>{err.status + " : " + err.statusText}</h3>
			</>
		);
	};
	export default Error;

- Creating the multiple Children routes in React using react-router-dom
- Things we are using to create a children are	
	1. children : []
	2. Outlet : Which is like tunnel and used to show the child component and it comes from the react-router
	3. Example:
		import { createBrowserRouter, RouterProvider, Outlet } from "react-router";
		
		const AppLayout = () => {
		return (
			<div className="app">
			<Header />
			<Outlet />
			</div>
		);
		};
		const appRouter = createBrowserRouter([
		{
			path: "/",
			element: <AppLayout />,
			children: [
			{
				path: "/",
				element: <Body />,
			},
			{
				path: "/about",
				element: <About />,
			},
			{
				path: "/contact",
				element: <Contact />,
			},
			],
			errorElement: <Error />,
		},
		]);
		
		//Create Root Element using ReactDOM
		const root = ReactDOM.createRoot(document.getElementById("root"));
		
		//Render the heading to DOM
		root.render(<RouterProvider router={appRouter} />);

	* By using link, React router dom never refresh the entire screen instead it will refresh the components. This is where we come to that React is the Single Page Application.

- Dynamic Routing	
	* how we are creating the dynamic routing
	* same as router but we need to use /:resId => resId is parameter which will be used to fetch the Id using => useParams

				path: "/restaurant/:resId",
				element: <RestaurantMenu />,
			  },

		);
	};
	return (
		<>

			<li>Paneer Butter Masala</li>
