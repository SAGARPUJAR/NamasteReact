Props Drilling: 
- When application grows there will be many components and componenets are related to each other.
- one way data stream in React -> Executes from the Top to bottom

The problem with passing props
- Passing props is great way to explicitly pipe data through your UI tree to the componenets that use it.
- But passing props can be become verbose and incovenient when you need to pass some prop deeply through the tree or if many components need the same props.

so some times we want to fetch the data from one compoenet to another but if the hieracy is too big we need to pass the values to each compoenets and get the value in the Child compoenent -> TO improve this React introduced concept called Context API.


-----------------------------------
React Context: 
- Context API solves the Propes drilling
- Create a Context and access anywhere in the application 
- In Fucntion Components -> we fetch using useContext
- In Class Compoenets    -> we fetch using <Context.Consumers></Context.Consumers>


Example:
import { createContext } from "react";

const UserContext = createContext({
  loggedInUser: "SAGAR PUJAR",
});

export default UserContext;
    
//Class base Components
<div>
          LoggedIn User:
          <UserContext.Consumer>
            {({ loggedInUser }) => <h1>{loggedInUser}</h1>}
          </UserContext.Consumer>
        </div>

Providing the Context to Entire Application:
Example: Showing the username in the whole application by Creating the authentication and setting up in the user
UserContext:
import { createContext } from "react";

const UserContext = createContext({
  loggedInUser: "Default User",
});

export default UserContext;


//App.js
import UserContext from "./utils/UserContext";
const AppLayout = () => {
  //Authentication
  const [userName, setUserName] = useState();
  useEffect(() => {
    // Make an API CALL & send username and Password
    const data = {
      name: "Sagar Pujar",
    };
    setUserName(data.name);
  }, []);

  return (
    // Proviging the content to entire application 
    // Access anywhere in the entire applicaiton
    <UserContext.Provider value={{ loggedInUser: userName }}>
      <div className="app">
        <Header />
        <Outlet />
      </div>
    </UserContext.Provider>
  );
};
