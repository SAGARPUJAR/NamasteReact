Tailwind CSS: Rapidly build modern websites without ever leaving your HTML
Configuring the Tailwind CSS to react application:
- Goto https://tailwindcss.com/docs/installation/using-vite
- select the Framework Guides
	- select Parcel  beacause we are using the Parcel
	- https://tailwindcss.com/docs/installation/framework-guides/parcel
- Install Tailwind CSS with Parcel
	- Install Tailwind CSS : npm install tailwindcss @tailwindcss/postcss
- Configure PostCSS: Create a .postcssrc file in your project root, and enable the @tailwindcss/postcss plugin. (- postcss: is tool for transforming the css with Javascript) 
	>	{ 
			"plugins": {
				"@tailwindcss/postcss": {}
			}
		}
- Import Tailwind CSS : Create a ./src/index.css file and add an @import for Tailwind CSS.
	- @import "tailwindcss";
	
- Start your build process
	> npm start
